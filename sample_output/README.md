# Curated Sample Output

This Git-tracked directory contains frozen representative scenarios and reviewer
assets. It is reference material, not authoritative execution history, and it may
not reflect the latest governed run. Normal CLI and Streamlit execution must never
write here.

Live run evidence remains under `runs/<run-id>/sdlc-artifacts/`. Successful
products are published under `projects/<project-name>/` with a manifest-verified
evidence copy at `projects/<project-name>/sdlc-artifacts/`; the original run bundle
remains retained under `runs/`.
